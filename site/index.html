Keyboard shortcuts

⌘/Ctrl + P
Toggle always-on-top pin
⌘/Ctrl + Shift + F
Toggle fullscreen
⌘/Ctrl + ,
Open settings
J
Jump to current minute
Arrows / Home / End

Esc
Close settings, exit fullscreen, or clear selection

Architecture

Runtime
Native Rust binary with GPUI
Rendering
Metal on macOS, DirectX on Windows, Vulkan on Linux
Storage
Single local settings.json file in OS config dir
Network
Zero network requests, zero telemetry
Timekeeping
System local clock with IANA timezone & DST detection
