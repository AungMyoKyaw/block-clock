Privacy Policy for Block Clock

Effective Date: November 2026

Block Clock is an offline, privacy-first desktop clock application designed for deep focus.

Data Collection

Block Clock does not collect, store, track, or transmit any personal data, usage metrics, telemetry, or device identifiers.

Local Storage

All configuration options (such as theme preference, 12h/24h format, and window positioning) are stored purely locally on your device in your user configuration directory.

Network Access

Block Clock operates completely offline and makes zero external network requests.

Contact

For questions or support, visit the GitHub repository at https://github.com/AungMyoKyaw/block-clock.
